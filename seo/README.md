# seo/

Working files for search and AI-answer visibility. Nothing here is served by the site.

| File | What it is |
|---|---|
| `keyword-map.csv` | Target keywords, intent, target URL, priority and status. Volume and difficulty are `TODO` until pulled from an SEO tool |
| `briefs/` | Article briefs: best spray tan booking software, Mangomint vs GlossGenius vs Happli, spray tan cancellation policy template |
| `templates/` | Starting points for compare pages, feature pages, how-to articles and free tool pages |
| `tracking/README.md` | Search Console, Bing Webmaster Tools and IndexNow setup, plus the weekly ranking and AI-answer check |
| `aeo.md` | Tactics for being cited by AI answers |
| `robots.md` | Which crawlers are allowed or blocked in `public/robots.txt`, and why |

Content itself lives in `src/content/blog/` and `src/content/compare/`. See the root `README.md` for how to add a post.
