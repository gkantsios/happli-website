This is a **sample draft** for the guides section (step-by-step how-tos, for example "How to set a deposit policy for spray tans"). It is excluded from the build, the sitemap and the RSS feed because `draft: true` is set.

Copy this file, change the frontmatter, write the guide, and set `draft: false` when it's ready. Before the first guide goes live, switch on `sections.guides` in `src/config/site.ts`.
