This is a **sample draft** of a "Happli vs X" page. It is excluded from the build and the sitemap because `draft: true` is set.

## How to write a comparison page

- Compare only features that are built and shipped. Check the features page before you publish.
- Be fair to the other product, and date any claims about it with `updatedDate`.
- Set `competitor` to the other product's name.
